# Knowledge kinds

> Generated by `tools/gen-references.ts` from pai-portal `a4ece4fcf` (archived contract snapshot), `packages/contracts/src/knowledge`. Do not edit manually: regenerate.

Every kind has a strict template: unknown keys are rejected. `properties` contains exactly these keys. `refs` sections materialize edges on save.

## Classification heuristic

1. Is it a statement about the world or about what should be? → decision, business_rule, constraint, fact, objective.
2. Is it a recipe for action? → flow (if it belongs to the product), pattern, runbook.
3. Is it a warning about failure? → risk, gotcha, antipattern.
4. Is it a future intention or an open question? → task, question, assumption.
If nothing fits: note (standalone statement), concept (definition), reference (external source).
Structural kinds (module, screen, flow, action, integration, use_case, data_model, entity, component, actor, glossary_term) are chosen based on what they describe, not these questions. flow_run is not created manually: each flow test produces one.

Citation format: kb:<kind>/<slug>@r<revision>

## States

- `draft` (Draft): Draft: in progress; does not count as current knowledge.
- `proposed` (Proposed): Proposed: created by an agent in a kind decided by humans; awaiting confirmation.
- `active` (Current): Current: confirmed knowledge that agents must respect.
- `resolved` (Resolved): Resolved: a question, assumption, risk, or task closed with a resolution node.
- `superseded` (Replaced): Replaced by another node of the same kind (historical).
- `archived` (Archived): Archived: excluded from recall by default; reversible.
- `rejected` (Rejected): Rejected by a person; retains the reason in properties.rejection.

- `metric` (**required**; table; columns: name, unit, baseline, target): A metric with a baseline and target.
- `horizon` (**required**; date): Deadline (YYYY-MM-DD).
- `priority` (optional; enum; must|should|could): must, should o could.
- `rationale` (optional; markdown; ≤1500): Why it matters.
- `owner` (optional; text): Who is accountable for the objective.
- `notes` (optional; markdown; ≤2000): Additional observations that do not fit another section.
