Supports Pai Console 0.2.5+ and is pinned to `pai-portal` `release/0.2.5` at `b194c6195`. Source compatibility does not certify staging or production availability.

## Changes since 0.0.10

The synthetic platform-admin corporate inventory contains **305 tools: 123 reads and 182 writes**, adding `asset_read`.

- Images: agents can look at project images through `asset_read`, using the `assets` lists of `page_read`, `whiteboard_read` and `knowledge_get`, within documented size limits. Video stays metadata-only through `asset_get`. Knowledge node bodies count as asset uses.
- Links: writes refuse old Portal addresses (`LEGACY_LINK`); guidance and mocks use current slug addresses.
- New evaluation `asset-read-image`.

See the [integration checkpoint](../upstream-sync-0.0.11.md) and [verification](../verification.md).
