# Pai Console 0.0.12

Release preparation date: 2026-11-03, America/Mexico_City. Draft; not published.

Source: pai-portal `release/0.2.5` at `47f888e08`. The generated inventory grows from 313 to 353 tools (141 reads, 212 writes). Details and limits: [integration checkpoint](../upstream-sync-0.0.12.md).

## Changes

- **One plugin.** `pai-console` now carries the vendored upstream `herdr` skill (pinned `v0.9.5`, sha256 provenance), the generic `orchestration` skill (worktree rule, typed orchestrators, no idle waits) and the wake Herdr plugin (`PAI_WAKE_SSH_OPTS`, `PAI_WAKE_REMOTE_PATH`, agent-keyed token cache). No `dependencies`. The `pai-orchestration` and `herdr` marketplace entries are removed with `renames: null` and `forceRemoveDeletedPlugins`, so installed copies are uninstalled. A daily workflow opens a pull request on a new Herdr release; it never merges. The Codex packages carry both skills as well, explicit use only. See [docs/orchestration.md](../orchestration.md).
- New `spaces` skill: Pai DB Spaces (versions, publish, deploy) and records (query, create, update with optimistic concurrency, events, actions) with literal error codes.
- `iam`: service accounts and their tokens (secrets are shown once), staff grants, the caller's own bindings, binding `justification` and `etag`.
- `organizations`: **breaking for older prompts:** connection tools no longer accept `organizationId`; `connection_list` has `scope`; pairing approval and terminals are covered; `agent_routine_delete` is documented.
- `products`: manifest, app client registration and versions with their breaking-change rule. `crm`: loss correction, delivered deals, workspace join by opportunity. `api-design`: revision comparison. `tasks` and `schedule`: record tasks, closed projects and banned assignees.
- Generated references, tool inventories and the three Codex packages are regenerated at version 0.0.12.
