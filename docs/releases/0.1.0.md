# Pai Console 0.1.0

Release preparation date: 2026-11-03, America/Mexico_City. Draft; not published.

## Changes since 0.0.11

- **Herdr skill dependency (ATE-709).** New marketplace entry `herdr`: source `git-subdir`, `https://github.com/herdrdev/herdr.git`, path `skills/herdr`, `ref` `v0.9.5`, `sha` `2ecf19a92fc3a7fff75b6ce3655ef04f4625ec01` (the annotated tag object is `7573e821895d32c8d1f78b3f6c9a2f85a46df4ac`). `pai-console` declares `dependencies: ["herdr"]`. The URL is the full HTTPS form on purpose: the `owner/repo` shorthand clones over SSH, which fails on machines without a github.com host key.
- **Codex vendoring.** `vendor/herdr` holds the same upstream commit with a sha256 record; `tools/build_codex.py` copies it into the three Codex packages and its check fails on drift from the marketplace pin. `tools/vendor_herdr.py` refreshes it.
- **New skill `orchestration`** (English, generic): never go idle with work in flight, report to the parent named in the brief, close with a handoff, and use the wake plugin. Roles and process come from the brief and the organization's decision records.
- **New Herdr plugin `herdr-plugins/orchestration-wake`** (event hooks; installed with `herdr plugin install`, not by Claude Code). It never wakes the pane itself, sends each target at most one wake per interval (default 60 s) and does not repeat a `blocked` wake. The example host aliases in `config.env.example` are placeholders.
- **Version** 0.0.11 to 0.1.0 (minor: new skill, new dependency).

## What this release does not establish

No tag or release is published. The herdr versions on the three machines are aligned separately. Fresh-install acceptance, real OAuth and desktop checks are recorded in the issue evidence, not here.
